## Tracking

All top-level site pages include the Google Tag Manager header snippet for container `GTM-NHCC2BZN`.
Any new page added to the site should include that same snippet inside the `<head>` section.
Any new page added to the site should also include the Google Tag Manager `<noscript>` iframe immediately after the opening `<body>` tag.
